Das Wichtigste

Beim Aufruf der Website werden technische Daten verarbeitet, die für die Bereitstellung der Inhalte erforderlich sind. Weitere Angaben zur Datenverarbeitung findest du in den folgenden Abschnitten.

Hosting

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können technische Zugriffsdaten, darunter die IP-Adresse, verarbeitet werden, um die Inhalte auszuliefern.

Werke vom Art Institute of Chicago

Die Website bezieht Werkdaten und Bilder vom Art Institute of Chicago. Beim Abruf wird eine Verbindung zu dessen Servern hergestellt. Dabei wird die IP-Adresse an den jeweiligen Server übertragen.

Speicher im Browser

Die Website speichert ausgewählte Inhalte im lokalen Speicher des Browsers. Diese Daten werden dort auf deinem Gerät abgelegt. Du kannst sie über die Einstellungen deines Browsers löschen.
